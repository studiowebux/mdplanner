# Release Checklist — Mobile App

## Before submission
- [ ] Bump build number and version string.
- [ ] Run the full smoke suite on iOS and Android.
- [ ] Verify deep links resolve to the right screen.
- [ ] Screenshots updated for store listings.

## After submission
- [ ] Tag the release commit.
- [ ] Post release notes in the team channel.
- [ ] Watch crash-free rate for 48h before promoting.
