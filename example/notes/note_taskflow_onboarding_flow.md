# Onboarding Flow — Decisions

## Goal
New users reach their first created task in under two minutes.

## Steps
1. Pick an identity (no password in the demo).
2. Land on the board with seeded sample tasks.
3. Inline "create your first task" prompt on an empty column.

## Notes
The empty-state prompt converts much better than a separate tutorial. Keep
the sample tasks clearly labelled so they are easy to delete later.
