# Mobile App v1 Scope

Initial scope for the first public mobile release. Reviewed with the mobile guild.

## Must Have

- Secure login with biometric unlock
- Task list and detail views
- Offline-first read access
- Push notifications for assignments

## Should Have

- Offline edits with background sync
- Home screen widgets
- Pull-to-refresh on all lists
- Dark mode following system setting

## Could Have

- Quick-add via share sheet
- Haptic feedback on actions
- In-app onboarding tour

## Won't Have

- Tablet-optimized layout
- Apple Watch companion app
- In-app purchases
