# Analytics Dashboard Rollout

Scope for the analytics dashboard general availability.

## Must Have

- Core delivery metrics (throughput, cycle time)
- Theme-reactive SVG charts
- Date range selector
- CSV export

## Should Have

- Drill-down to record level
- Saved dashboard views
- PDF export
- Role-based default layouts

## Could Have

- Scheduled email reports
- Custom metric builder
- Comparison against previous period

## Won't Have

- Real-time streaming charts
- Embedded external BI tools
- White-label dashboards
