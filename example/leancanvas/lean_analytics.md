# Analytics Dashboard Lean Canvas

## Problem

- Teams ship features blind to actual usage
- Data lives in tools nobody opens
- Custom reporting needs an analyst
- Insights arrive too late to act on

## Solution

- Auto-generated dashboards from product events
- Plain-language metric explanations
- Self-serve report builder, no SQL
- Weekly digest pushed to where teams work

## Unique Value Proposition

Answers, not charts — know what to do next, not just what happened.

## Unfair Advantage

- Native event stream from the core product
- Opinionated metric library tuned for SaaS
- No third-party data pipeline to maintain

## Customer Segments

- Product managers
- Founders tracking north-star metrics
- Growth and marketing teams
- Customer success leads

## Existing Alternatives

- Spreadsheets exported by hand
- Heavyweight BI tools (Looker, Tableau)
- Generic product analytics (steep setup)
- Gut feeling

## Key Metrics

- Dashboards created per account
- Weekly digest open rate
- Report-builder adoption
- Time-to-first-insight

## High-Level Concept

"A data analyst on the team, minus the hiring"

## Channels

- Bundled with the core product
- Analytics-focused webinars
- Template gallery for common funnels
- Partner integrations

## Early Adopters

- Data-curious PMs
- Seed-stage founders
- Existing power users

## Cost Structure

- Event storage and query compute
- Charting and export infrastructure
- Data engineering time
- Support

## Revenue Streams

- Pro analytics add-on: $20/month
- Included at Business tier
- Usage-based event overage
