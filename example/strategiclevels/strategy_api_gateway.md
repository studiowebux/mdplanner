# API Gateway Strategy 2026

## Vision

- (vision_1) Make the platform programmable for every customer

## Mission

- (mission_1) Provide a stable, documented, and secure public API

## Goals

- (goal_1) Publish a versioned public REST API
- (goal_2) Onboard 50 integration partners
- (goal_3) Reach 1M authenticated API calls per month

## Objectives

- (obj_1) Maintain 99.95% gateway availability
- (obj_2) Keep p95 latency under 150ms
- (obj_3) Document 100% of public endpoints

## Strategies

- (strat_1) API-first design with OpenAPI as the contract
- (strat_2) Tiered rate limiting tied to plan level
- (strat_3) Developer portal with self-serve keys

## Tactics

- (tactic_1) Contract tests on every endpoint in CI
- (tactic_2) Deprecation policy with 90-day notice
- (tactic_3) Quarterly partner feedback sessions
