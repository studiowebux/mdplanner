## Key Partners

- Cloudflare (edge)
- Auth0 (token issuance)
- OpenAPI tooling vendors
- Integration partners

## Key Activities

- Gateway and routing operation
- API versioning and deprecation
- SDK generation
- Developer-portal upkeep

## Key Resources

- Platform engineering team
- OpenAPI source of truth
- Edge infrastructure
- Rate-limit and auth primitives

## Value Proposition

- One secure, documented API door
- Integrations in hours, not weeks
- Policy enforced at the edge
- Backward-compatible by default

## Customer Relationships

- Developer portal and docs
- Partner onboarding program
- Versioned change notices
- Premium support for enterprise

## Channels

- Developer portal
- Generated SDKs
- Technical blog
- Partner program

## Customer Segments

- Integration partners
- Internal product teams
- Enterprise customers
- Third-party developers

## Cost Structure

- Edge compute (35%)
- Platform engineering (45%)
- Docs portal hosting (5%)
- Security audits (15%)

## Revenue Streams

- Enterprise API access tier
- Usage-based call pricing
- Premium partner support
