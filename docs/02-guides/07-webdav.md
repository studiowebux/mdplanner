# WebDAV

> **Not available in v2 yet.**

WebDAV support is planned for a future v2 release. It will expose the project
directory over WebDAV at `/webdav`, enabling editing markdown files with any
WebDAV-compatible application (Obsidian, Finder, davfs2, Neovim + netrw, etc.).

Watch the [GitHub releases](https://github.com/studiowebux/mdplanner/releases)
for updates on when WebDAV lands in v2.
